*Cinematic. Clear. Consistent.*

Style guide split out of `Cinematic_Visual_Reference_Pack-2.png`.

## Design principles
- Minimal & expressive character
- Cinematic lighting
- Meaningful environments
- Clear visual hierarchy
- Consistent style

## Technical guidelines
- 16:9 aspect ratio
- 1920x1080 resolution
- 24 fps
- Clean composition
- No excessive effects

## Color palette
Deep navy -> slate blue -> dusty mauve -> lavender grey -> peach -> warm orange -> burnt orange

## Not split out
Props and Style References panels from the source sheet have no folder in this structure, so they were left out.

## Note
These are crops of a single 1536x1024 image, so each file is low resolution (roughly 160-500 px wide). Use them as references, not final assets.
